## Projects

**[Watchtower](https://github.com/Shubham21102005/api-monitoring-system)**: self-hosted API uptime monitoring. BullMQ on Redis for scheduling, jobs survive restarts, per-monitor retries so transient blips don't page you, Resend email alerts, and a 30-day request/response audit trail. Node, Express, React, MongoDB.

**[CodePulse](https://github.com/Shubham21102005/codebase-intelligence-platform)**: ask a GitHub repo questions in plain English. Tree-sitter parses the code, embeddings go into Qdrant, answers come back with the relevant source inline in a Monaco viewer. FastAPI, Next.js, LangChain. [Live](https://codepulse-xi.vercel.app)

**[AI Mock Interview](https://github.com/Shubham21102005/AI_Mock_interview_Platform)**: generates role-specific questions from a resume and job description, runs the interview over voice with the Web Speech API, and scores answers on clarity and technical depth. Next.js, Express, MongoDB. [Live](https://interview-ai-woad.vercel.app)
